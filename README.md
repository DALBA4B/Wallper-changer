# Wallpaper Changer

Максимально лёгкий скрипт, который ставит случайные обои на рабочий стол при каждом включении ПК. Без Python, без зависимостей, ничего не висит в памяти.

## Возможности

- Случайная обоина из вашей папки при каждом входе в систему
- Никогда не повторяет предыдущую картинку подряд
- Работает на встроенном в Windows PowerShell — ничего устанавливать не нужно
- Скрипт выполняется за доли секунды и сразу завершается: не занимает ОЗУ и не грузит систему
- Поддерживает `.jpg`, `.jpeg`, `.png`, `.bmp`

## Установка

1. Скачайте репозиторий и распакуйте в любую папку.
2. Запустите двойным кликом **`START.bat`** и выберите пункт **1. Установка**.
3. В открывшемся окне выберите папку, **откуда брать обои**.
4. Затем выберите папку, **куда установить** программу.

Готово! Установщик сам создаст автозапуск и запомнит папку с обоями.

Дальнейшее управление — через то же меню `START.bat`: смена папки обоев, перенос программы, удаление.

## Как это работает

- `wallpaper.ps1` — выбирает случайную картинку и устанавливает её обоями (через WinAPI `SystemParametersInfo`).
- `START.bat` — единая точка входа с меню: установка, смена папки обоев, перенос, удаление.
- `install.ps1` — установщик: показывает окна выбора папок, сохраняет путь к обоям в `config.txt` и создаёт скрытый ярлык в автозагрузке Windows.
- `manage.ps1` — смена папки обоев и перенос программы (перевешивает автозагрузку на новое место).
- `uninstall.ps1` / `UNINSTALL.bat` — полное удаление: снимает автозагрузку и предлагает стереть файлы программы.
- `config.txt` — путь к папке с обоями (создаётся установщиком в папке установки).
- `last_wallpaper.txt` — хранит путь к последней обоине, чтобы она не повторялась.

## Удаление

Запустите **`START.bat`** и выберите пункт **4. Удалить** — программа уберёт себя из автозагрузки и предложит удалить свои файлы. (Файл `UNINSTALL.bat` делает то же самое напрямую.)
